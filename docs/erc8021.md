# ERC-8021 Attribution Boundary

Base Builder Codes attribute onchain activity by appending an ERC-8021 `dataSuffix` to transaction calldata.

Base Receipt currently initiates payments with Base Pay. The project must not claim Builder Code attribution for these payments unless the payment transaction path explicitly supports supplying or inheriting a valid `dataSuffix`.

## Safe integration plan

After Base Dashboard registration provides a Builder Code:

- Base App traffic: rely on Base App automatic attribution after the app is registered, then verify that attribution appears in Dashboard analytics.
- External web traffic: add ERC-8021 only to transaction clients/calls that officially support `dataSuffix` (for example a Wagmi/Viem client or a supported wallet capability).
- Keep payment verification independent of attribution. A valid payment receipt must never depend on whether Builder Code indexing succeeds.
- Verify attributed transactions with Base Dashboard or the official Builder Code validation tooling before marking attribution as active.

## Non-goal

Do not append arbitrary bytes manually to Base Pay payment identifiers or alter verified payment data solely to manufacture attribution. Attribution is analytics metadata, not part of receipt correctness.
