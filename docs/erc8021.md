# ERC-8021 Attribution Boundary

Base Builder Codes attribute onchain activity by appending an ERC-8021 `dataSuffix` to transaction calldata.

Base Receipt sends the USDC transfer directly through an injected EVM wallet and physically appends the ERC-8021 suffix to the top-level transaction calldata. Receipt correctness remains independent of attribution.

## Verified integration

- Builder Code: `bc_87fjmj1l`
- Direct transaction: `0xa7c0d15e190b7ab099c03013b14f07c6a58a7c15c8c1e7a8132bb7512c9e881d`
- The top-level transaction input contains the encoded Builder Code immediately after the USDC transfer arguments.
- Keep payment verification independent of attribution. A valid payment receipt must never depend on whether Builder Code indexing succeeds.
- Base Dashboard display may lag the confirmed onchain transaction while it indexes activity.

## Non-goal

Do not alter payment identifiers or receipt verification data to manufacture attribution. The ERC-8021 suffix belongs only on transaction calldata and remains analytics metadata, not part of receipt correctness.
